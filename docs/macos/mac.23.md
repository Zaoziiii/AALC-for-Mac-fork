# AALC Mac mac.23 更新说明

下载：[v1.0.9-mac.23](https://github.com/Zaoziiii/AALC-for-Mac/releases/tag/v1.0.9-mac.23)

## mac.15 – mac.23 更新内容

**镜牢**
- 瓦尔普吉斯之夜等活动期间，驾驶页的布局会变，镜牢按钮变小并上移。现在旧位置认不出时，会按活动布局找镜牢入口。活动结束后仍按原来的位置识别。（mac.23）
- 观测 EGO 饰品的体系标签按实测间距点击。以前选「泛用」会点到「打击」。（mac.22）
- 选初始饰品时，列表拖不动、一直往下滑、不选右侧饰品的问题已修复。（mac.21）
- 激进合成饰品时，推算出画面外的格子不再中断镜牢，会跳过这次点击。（mac.20）
- 事件结束、回到地图时，判断门槛从 0.90 降到 0.85，不再卡在事件里。（mac.15）
- 新增选项：后台寻路不拖地图，按巴士旁的箭头逐步走，完全不占用鼠标。默认关闭。（mac.16）

**后台拖动**
- 在 CrossOver 下，游戏按住鼠标拖动时看的是真实鼠标的位置。所以以下拖动现在也会短暂借用鼠标：
  - 战斗连线，包括小指良单通防御、避免或优先 3 技能；
  - 选主题包时往下拖；
  - 各种列表拖动。
- 借用前会等键鼠空闲 1.5 秒，拖完把光标放回原位。拖动过程中请不要动鼠标。（mac.19、mac.21）

**窗口与主页**
- 游戏窗口自己挪动几个像素时不再停止。（mac.17）
- 开始任务时检查窗口尺寸，被 CrossOver 撑大时自动调回 1920×1080，只改窗口大小，不移动鼠标。在主页误开 Settings 菜单时，点 Return 关掉，不再反复按 Esc。（mac.18）
- 「游戏被切到前台，已切回…」每次运行只提示一次，之后只写进调试日志。（mac.20）

## 已知限制

- 小指良单通连续防御与原版逻辑一致：连线后 2 秒内没有开打，会按 P+Enter，这一回合就变成按胜率自动出招，不再是防御。
- 活动布局的镜牢按钮只截了英文版。
- 只在 CrossOver 下测试过。腾讯应用宝 Mac 版等其他 Wine 外壳未验证。
- Intel Mac、自定义 Steam 库路径、多份游戏安装未验证。

## 验证范围

源码测试 143 项，其中 1 项需要游戏正在运行。mac.15–mac.23 的各项修复都按实机日志和截图核对过，但这一版没有完整跑过一整局镜牢。应用包版本为 `1.0.9`（build 23），解压后已通过严格签名检查。
